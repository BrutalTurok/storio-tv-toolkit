# DOOM button map for the Storio TV
# Copy this file to the console with:  adb push doom_buttons.txt /sdcard/doom_buttons.txt
# (Install-DOOM.ps1 and Play-DOOM.ps1 do this for you.)
# Format:  Android_key_code=action[,second_action]
# To find the code of each controller button, run "Show-Buttons.ps1" and press the buttons.
# Lines starting with r are VTech controller buttons (shown as "VTech button rNNN").
# Actions: up down left right fire use run strafe strafe_left strafe_right
#          menu enter map yes no next_weapon prev_weapon 1 2 3 4 5 6 7 pause backspace
# (The old Spanish names and the old file name /sdcard/doom_botones.txt still work.)
